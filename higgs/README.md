# higgs

The abelian Higgs model in three dimensions.

- [`symmetric_phase/`](symmetric_phase/): the symmetric phase. Torus limits, the Osterwalder–Schrader axioms with cubic symmetry, and clustering on ergodic components.
- [`curvature_rotations/`](curvature_rotations/): Euclidean invariance ℝ³ ⋊ O(3) and clustering for the curvature field, from reflection positivity at the diagonal planes.
